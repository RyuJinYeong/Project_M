# 개인 환경 설정 및 로비 수명주기 테스트

## 개인 환경 설정

- [ ] 게임 중 ESC 도움말에 `조작법 / 게임 규칙 / 환경 설정` 세 탭이 표시된다.
- [ ] 환경 설정 탭을 열어도 이동, 시점 회전, 공격, 문, 직업 행동 입력은 실행되지 않는다.
- [ ] 마우스 감도를 변경하면 도움말을 닫은 직후 시점 회전 속도에 반영된다.
- [ ] 전체 음량을 변경하면 게임 효과음과 음성 출력의 최종 음량에 반영된다.
- [ ] 음성 채팅 음량을 변경하면 Vivox 수신 음량에 즉시 반영된다.
- [ ] 마이크와 음성 수신을 환경 설정에서 끄고 켤 수 있고 우상단 음성 아이콘 상태와 일치한다.
- [ ] 화면 모드, 해상도, 그래픽 품질, FPS 제한을 변경하면 즉시 반영된다.
- [ ] 게임을 종료하고 다시 실행해도 마지막 개인 설정이 유지된다.
- [ ] 1920x1080 및 대표적인 16:10 해상도에서 설정 항목과 하단 버튼이 겹치지 않는다.

## 같은 Relay 방으로 전체 복귀

- [ ] 호스트가 경기 중 ESC의 `로비로 돌아가기`를 확정하면 참가자 전원이 LobbyScene으로 이동한다.
- [ ] 복귀 후 호스트와 모든 클라이언트의 로비 참가자 목록이 동일하다.
- [ ] 복귀 전 방 코드와 복귀 후 표시되는 방 코드가 동일하다.
- [ ] 복귀 후 기존 방 코드로 새로운 클라이언트가 참가할 수 있다.
- [ ] 같은 인원으로 두 번째 경기를 시작해도 NetworkManager, LobbyRoomManager, MatchManager 중복 오류가 없다.
- [ ] 두 번째 경기 종료 후에도 같은 방으로 다시 복귀할 수 있다.

## 클라이언트 단독 이탈 후 재사용

- [ ] 일반 클라이언트가 경기 중 혼자 로비로 나가면 호스트와 나머지 인원의 경기는 계속된다.
- [ ] 이탈한 클라이언트는 NGO Shutdown이 끝날 때까지 방 생성·참가 입력을 할 수 없다.
- [ ] 이탈 완료 후 같은 프로세스에서 새 Relay 방을 생성할 수 있다.
- [ ] 이탈 완료 후 같은 프로세스에서 다른 방 코드로 참가할 수 있다.
- [ ] 이탈한 클라이언트가 원래 방 코드로 다시 참가할 때 진행 중 경기라면 서버가 참가를 거절하고 로그인 화면으로 복구한다.

## 호스트 세션 종료 및 예기치 않은 종료

- [ ] 로비에서 호스트가 `방 나가기`를 누르면 기존 방 코드는 더 이상 참가에 사용할 수 없다.
- [ ] 경기 종료 또는 중도 포기로 같은 Relay 로비에 복귀한 호스트가 `방 나가기`를 누르면 영속 RelayConnectionManager를 통해 NGO Shutdown이 시작된다.
- [ ] 복귀한 LobbyScene에 새로 생성됐다가 파괴되는 중복 NetworkManager를 LobbyUI가 참조하지 않고, 기존 영속 NetworkManager의 연결을 정상 종료한다.
- [ ] 복귀 후 호스트가 방을 나가면 로그인 화면에서 `네트워크 연결을 종료하는 중입니다.` 이후 `로비에서 나왔습니다.`로 상태가 갱신된다.
- [ ] 복귀 후 방 나가기를 완료한 호스트가 같은 프로세스에서 새 방 생성과 다른 방 참가를 정상 수행할 수 있다.
- [ ] 호스트가 프로세스를 종료하거나 인터넷 연결을 잃으면 클라이언트가 로그인 화면으로 복구된다.
- [ ] 호스트 연결이 끊긴 클라이언트가 같은 프로세스에서 새 방 생성과 다른 방 참가를 각각 수행할 수 있다.
- [ ] 위 과정에서 `Singleton is not null`, 중복 NetworkManager, Shutdown 진행 중 StartHost/StartClient 오류가 발생하지 않는다.
