# Project M 멀티플레이 수동 테스트 체크리스트

최종 갱신: 2026-08-13

이 문서는 구현을 우선 진행하는 동안 보류한 다인 플레이 검증 항목을 누적한다. 체크는 실제 빌드 또는 MPPM 환경에서 해당 시나리오를 끝까지 재현한 뒤에만 완료한다.

## 공통 준비

- [ ] 로비 닉네임 입력창은 한글·영문 모두 최대 8자까지만 입력되고, 9번째 글자는 추가되지 않는다.
- [ ] 기존 PlayerPrefs에 9자 이상의 닉네임이 저장되어 있어도 로비 진입 시 8자로 잘려 표시되고 서버 등록 이름도 8자를 넘지 않는다.
- [ ] 직접 연결 테스트 런처의 호스트·클라이언트 자동 닉네임이 각각 8자 이내이면서 서로 중복되지 않는다.
- [ ] 호스트 1명과 클라이언트 3명 이상이 직접 연결 테스트 런처로 로비에 자동 참가한다.
- [ ] 자동 참가 후 게임이 자동 시작되지 않고, 호스트가 로비 설정을 바꾼 뒤 수동으로 시작할 수 있다.
- [ ] 최대 13명이 참가했을 때 모든 플레이어에게 서로 다른 집과 역할 상태가 정상 배정된다.
- [ ] 호스트와 각 클라이언트의 Console에 NGO 권한 위반, RPC 대상 오류, NetworkVariable 쓰기 오류가 없다.
- [ ] 한 경기를 끝내고 로비로 돌아간 뒤 두 번째 경기를 시작해도 이전 역할, 살해 담당, 인형, 드롭 도구, 음성 채널 상태가 남지 않는다.

## 역할 배정과 표시

- [ ] GameScene 진입 후 직업 정보를 기다리는 클라이언트에 `직업 배정 중`과 `준비 완료 N / M`이 표시된다.
- [ ] 모든 연결 플레이어의 직업 배정 확인이 서버에 도착하기 전에는 첫 아침 투표가 시작되지 않는다.
- [ ] 고지연 클라이언트가 45초 안에 직업 정보를 수신하고 확인하면 로비로 돌아가지 않고 정상적으로 경기를 시작한다.
- [ ] 한 명이라도 45초 동안 직업 배정을 확인하지 못하면 일부 인원만으로 시작하지 않고 전원이 같은 Relay 로비로 돌아간다.
- [ ] 직업 배정 대기 중 플레이어가 연결 해제되면 남은 인원만으로 시작하지 않고 전원이 같은 Relay 로비로 돌아간다.
- [ ] 집·육체·영체 배정에 일부라도 실패하면 경기를 강제로 진행하지 않고 전원이 같은 Relay 로비로 돌아간다.
- [ ] 배정 실패 복귀 후 방 코드, 참가자 목록과 로비 설정이 유지되고 실패 사유가 로비 상태 문구에 표시된다.
- [ ] 배정 실패 복귀 후 다시 게임을 시작하면 이전 실패 문구와 준비 인원 수가 초기화되고 새 배정으로 정상 시작된다.
- [ ] 마을 생성 직후 모든 집의 `SpawnPoints/FenceAnchor_A`, `FenceAnchor_B`가 인식되고 인접한 집 사이 내부 울타리가 빠짐없이 생성된다.
- [ ] 각 플레이어가 방에 들어가면 해당 집 상단에 집주인 닉네임이 모든 클라이언트에서 표시된다.
- [ ] 살아 있는 집주인의 닉네임 TMP가 비활성화되거나 `(사망)`으로 덮어써지지 않는다.
- [ ] 집주인이 사망하면 닉네임과 사망 상태가 함께 표시되고, 다음 경기 집 재배정 시 이전 표시가 남지 않는다.
- [ ] 주민 역할 풀에는 농부, 잡역부, 대장장이, 집행관, 의원, 수사관, 주정뱅이, 퇴마사, 검시관, 사냥꾼, 영매사, 장의사, 행상인만 배정된다.
- [ ] 마녀 역할 풀에는 마녀, 저주술사, 내통자, 잠입자만 배정된다.
- [ ] 이방인 역할 풀에는 도둑, 살인귀, 순교자만 배정된다.
- [ ] 살인귀와 순교자는 한 경기에 각각 최대 한 명만 무작위 배정되고, 남는 이방인 슬롯은 도둑으로 채워진다.
- [ ] 기존 MurderousFiendToggle과 MartyrToggle이 각각 살인귀와 순교자 필수 역할 설정으로 동작한다.
- [ ] 위조범, 일반 Mafia, 빙의령, 복수귀가 신규 배정과 필수 역할 UI에 나타나지 않는다.
- [ ] 역할명과 진영명이 주민, 마녀, 이방인 및 최신 한국어 역할명으로 표시된다.

## 아침 투표 확정과 조기 집계

- [ ] 경기 시작과 밤 결과 종료 뒤 별도의 아침 회의 페이즈를 거치지 않고 바로 아침 투표 페이즈가 시작된다.
- [ ] 로비에는 아침 투표시간 입력 하나만 표시되고 기본값은 60초다.
- [ ] 아침 투표시간 동안 생존자는 기존 아침 음성 채널을 계속 사용하고 대화 탭과 투표 탭을 자유롭게 전환할 수 있다.
- [ ] 아침 투표 시작 시 영체 귀가, 투표 초기화 및 이전 밤 결과 정리가 한 번씩만 실행된다.
- [ ] 생존 플레이어 중 한 명이라도 투표를 확정하지 않았다면 기존 투표 종료 시각이 유지된다.
- [ ] 기권 확정을 포함해 모든 생존 플레이어가 투표를 확정하면 남은 투표시간이 5초로 단축된다.
- [ ] 남은 시간이 이미 5초 이하라면 모든 투표가 확정되어도 시간이 다시 늘어나지 않는다.
- [ ] 5초 카운트다운 뒤 기존 투표 집계와 투표 결과 페이즈가 한 번만 실행된다.
- [ ] 투표 중 플레이어가 연결 해제되면 방에 남은 생존자들의 확정 상태만으로 조기 종료 여부를 다시 계산한다.
- [ ] 기권 우세 결과는 `아무도 추방되지 않았습니다.`와 `기권: N표`만 표시하고, 후보 동률 결과는 동률 안내를 유지한다.

## 마녀 살해 담당과 팀 살해권

- [ ] 밤 준비 투표로 생존 마녀 중 한 명만 살해 담당자가 된다.
- [ ] 동률은 후보 중 무작위로 결정되고, 유효표가 없으면 생존 후보 중 무작위로 정해진다.
- [ ] 살해 담당자가 기절하거나 감금되어도 다른 마녀에게 살해권이 이전되지 않는다.
- [ ] 마녀는 독살, 저주술사는 저주 인형, 내통자와 잠입자는 직접 살해만 사용한다.
- [ ] 같은 밤에 마녀 팀의 살해 방식이 둘 이상 성공하지 않는다.
- [ ] 내통자가 살해 담당일 때 직접 살해와 위장 주민 능력을 같은 밤에 모두 사용할 수 없다.

## 텍스트 채팅

- [ ] 아침 투표 중 생존자는 대화 탭의 입력창과 전송 버튼 또는 Enter 키로 최대 120자의 메시지를 보낼 수 있다.
- [ ] 메시지를 전송하면 송신자와 허용된 수신자 모두의 `Content` 아래에 `ChatMessage` 행이 생성되고 닉네임, 본문, 시간이 표시된다.
- [ ] 가로 폭을 넘겨 두 줄·세 줄로 자동 줄바꿈된 메시지는 실제 줄 수만큼 행 높이가 늘어나고 위아래 메시지와 겹치지 않는다.
- [ ] 채팅 기록이 비어 있는 상태에서 첫 메시지로 두 줄·세 줄 메시지를 보내도 첫 줄이 상단 구분선이나 마스크에 겹치거나 가려지지 않는다.
- [ ] 여러 줄 메시지가 연속으로 추가되어도 각 행 사이의 기존 간격이 유지되고 `Content` 전체 높이와 최신 메시지 스크롤 위치가 정상 갱신된다.
- [ ] 아침 공개 채팅과 야간 비공개 채팅이 동일한 `ChatMessage` 프리팹을 사용하며, 새 메시지가 추가되면 스크롤이 최신 메시지로 이동한다.
- [ ] 아침 투표 중 사망자는 공개 채팅을 읽을 수 있지만 입력창과 전송 버튼은 비활성화되어 메시지를 보낼 수 없다.
- [ ] 아침 투표 이외 페이즈에서 조작한 공개 채팅 RPC는 서버가 거절하고 다른 클라이언트에 전달하지 않는다.
- [ ] 밤 준비와 밤 행동 중 생존 마녀에게만 좌하단 `야간 채팅` 창이 표시되고, 주민·이방인·사망 마녀에게는 표시되지 않는다.
- [ ] 야간 채팅 메시지는 생존 마녀들만 송수신하며 사망자와 다른 진영 클라이언트에는 전달되지 않는다.
- [x] 영매사의 교신 능력이 성공하면 해당 영매사와 선택된 사망자에게 좌하단 `영매사 채팅` 창이 표시된다. (MPPM 확인 완료)
- [ ] 여러 영매사가 같은 사망자를 선택하면 해당 영매사들과 사망자가 같은 텍스트 채널의 메시지를 모두 송수신한다.
- [ ] 영매사 채팅 연결이 종료되거나 밤 행동이 끝나면 양측의 영매사 채팅 창이 즉시 닫히고 이후 전송 요청은 거절된다.
- [ ] 좌하단 야간·영매사 채팅에서 120자 한글 메시지와 공백 없는 긴 문자열이 패널 가로 폭 안에서 줄바꿈되고, 실제 줄 수만큼 행 높이가 늘어나 앞뒤 메시지와 겹치지 않는다.
- [ ] 좌하단 채팅에 여러 줄 메시지가 연속으로 쌓여도 본문이 Viewport 밖으로 가로 돌출되지 않고 최신 메시지까지 세로 스크롤된다.
- [ ] 야간 채팅과 영매사 채팅은 Enter 키로 입력을 시작하고 Enter 전송 또는 Escape 취소 뒤 시점·이동·공격·문·횃불·직업 행동 입력이 정상 복원된다.
- [ ] 밤 준비 종료 순간 마녀 채팅 입력창을 선택하고 있거나 메시지를 작성 중이어도 입력 포커스가 해제되고 밤 행동의 시점·이동·공격·문·횃불·직업 행동 입력이 즉시 복원된다.
- [ ] 야간 채팅 또는 영매사 채팅 입력 중 WASD, E, F, 마우스 클릭을 사용해도 이동, 문 이용, 횃불, 직업 능력, 무기 공격이 실행되지 않는다.
- [ ] 메시지의 닉네임은 서버의 PlayerMatchState 값을 사용하고 `<`, `>`를 포함한 입력이 TMP 리치 텍스트로 해석되지 않는다.
- [ ] 같은 클라이언트의 0.75초 이내 연속 전송은 서버에서 제한되며 채팅이 중복 표시되지 않는다.
- [ ] 다음 아침과 다음 밤 시작 시 이전 날짜의 채팅 기록과 미전송 입력값이 남지 않는다.

## 저주술사와 저주 인형

- [ ] 인형이 없는 밤에는 살해 담당 저주술사에게만 최초 설치 F키 행동이 활성화된다.
- [ ] 최초 설치 전에는 저주술사 본인과 다른 클라이언트 모두에게 운반 인형이 표시되지 않는다.
- [ ] 자기 자신이 아닌 다른 생존 플레이어의 육체를 조준하고 F키를 3초간 유지하면 커서 게이지가 차고, 손을 떼거나 조준이 벗어나면 진행도가 초기화된다.
- [ ] 최초 설치가 서버에서 승인되는 순간 대상의 유효한 Home 포인트에 인형이 바로 표시되고 마녀 팀 살해 행동이 완료된다.
- [ ] 대상이 야외에서 자는 주정뱅이면 집의 Home 포인트가 아니라 현재 벤치 옆 Drunkard 포인트에 설치된다.
- [ ] 3초 시전 중 대상이 사망·연결 해제되거나 거리, 페이즈, 행동 가능 상태가 바뀌면 서버가 요청을 거절하고 다시 시도할 수 있다.
- [ ] 인형을 든 본인 화면에는 1인칭 앵커의 인형이 보이고, 다른 클라이언트에는 월드 앵커의 인형이 보인다.
- [ ] 운반 인형의 월드 표시 크기와 위치가 영체 애니메이션을 따라 자연스럽게 유지된다.
- [ ] 주민, 마녀, 이방인 모두 설치된 인형을 회수하고 다른 유효한 집에 재설치할 수 있다.
- [ ] 밤 종료 직전 늦게 도착한 습득 또는 설치 RPC가 결과 확정 뒤 상태를 바꾸지 못한다.
- [ ] 인형 보유자가 기절하면 살아 있는 보유자의 현재 유효한 Home 또는 주정뱅이 포인트로 반환된다.
- [ ] 인형 보유자가 감금되면 살아 있는 보유자의 현재 유효한 Home 또는 주정뱅이 포인트로 반환된다.
- [ ] 인형 보유자가 사망하거나 연결 해제되면 인형 상태가 None으로 초기화된다.
- [ ] 인형이 설치된 집주인이 사망하거나 연결 해제되면 인형 상태가 None으로 초기화된다.
- [ ] 인형으로 대상이 사망한 뒤 그 집에 인형이 남지 않고 상태가 None이 된다.
- [ ] 인형 살해는 의원 보호를 무시한다.
- [ ] 인형이 마녀 보유자 또는 마녀 집에 있으면 아군도 정상 사망한다.
- [ ] 인형이 사라진 뒤 다음 밤 저주술사가 다시 살해 담당자가 되면 새 최초 설치 행동이 정상적으로 활성화된다.
- [ ] 최초 설치를 완료하기 전에 저주술사가 기절·감금되면 인형이 생성되거나 자기 집으로 반환되지 않고 그 밤의 미사용 살해권도 이전되지 않는다.
- [ ] 저주술사가 이미 다른 집에 설치한 뒤 감금되면 인형이 이동하거나 복제되지 않는다.
- [ ] 살해 담당이 아닌 저주술사는 위장 도구의 가짜 주민 행동을 사용할 수 있다.
- [ ] 살해 담당 저주술사는 위장 도구 직접 살해를 사용할 수 없고 저주 인형만 사용한다.
- [ ] 저주술사의 최초 설치와 운반 후 재설치 성공 시 `저주 인형을 설치했습니다.`가 표시된다.
- [ ] 설치된 인형 습득 시 `저주 인형을 집어 들었습니다. 기절·감금 시 자신의 설치 포인트로 돌아갑니다.`가 표시된다.
- [ ] 집 밖에서 3회 피격되어 인형이 반환되면 해당 사유와 귀가 안내가 표시된다.
- [ ] 밤 종료 후 늦은 인형 요청과 행동 불가 상태의 상호작용에는 각각 지정된 거절 안내가 표시된다.
- [ ] 저주술사 밤 시작, 기절·감금 반환, 거리·설치 포인트 오류에는 별도의 저주 인형 하단 알림이 표시되지 않는다.

## 야외 피격과 인형 운반

- [ ] 집 밖의 모든 생존 영체는 유효 피격 시 넉백과 붉은 피격 표시를 받고, 표시 시간 동안 이동속도가 기본값의 75%로 감소한다.
- [ ] 야외 피격 감속은 역할과 진영에 관계없이 피격자 본인에게 적용되고 다른 플레이어의 이동속도에는 영향을 주지 않는다.
- [ ] 인형 보유자가 집 밖에서 첫 번째와 두 번째 유효 피격을 받아도 인형을 계속 들고 있다.
- [ ] 인형 보유자가 집 밖에서 세 번째 유효 피격을 받으면 인형이 즉시 자신의 유효한 Home 또는 주정뱅이 포인트로 반환된다.
- [ ] 공격 한 번의 스윕이 여러 프레임과 보간 지점에서 같은 영체를 겹쳐도 한 번만 피격 처리된다.
- [ ] 무기 히트박스가 빠르게 지나가도 서버의 보간된 OverlapBox 검사로 중간 경로의 영체를 판정한다.
- [ ] 서로 다른 집에 있거나 공격자와 피격자가 집 안/밖으로 갈린 경우에는 겹침이 있어도 피격이 승인되지 않는다.
- [ ] 타인의 집 안에서는 기존처럼 세 번째 피격 시 외부 감옥으로 이동하고, 인형을 들고 있었다면 감금 반환 규칙이 적용된다.

## 도둑과 드롭 도구

- [ ] E키 레이캐스트로 사망자가 떨어뜨린 도구를 거리 안에서만 습득한다.
- [ ] 도둑이 아닌 주민은 역할 계승 목적으로 드롭 도구를 습득할 수 없다.
- [ ] 도둑이 자기 자신이 떨어뜨린 도구나 이미 소비된 NetworkObject를 습득하지 못한다.
- [ ] 주민 도구를 훔치면 실제 사망자의 주민 역할과 주민 진영을 그대로 계승한다.
- [ ] 마녀 도구를 훔치면 외형상 위장 도구가 아니라 실제 사망자의 마녀 역할과 마녀 진영을 그대로 계승한다.
- [ ] 저주술사의 위장 도구를 훔치면 저주술사 역할을 계승한다.
- [ ] 이방인 도구를 훔치면 해당 이방인의 실제 역할과 이방인 진영을 그대로 계승한다.
- [ ] 역할 계승 직후 개인 역할 UI와 마녀 명단이 필요한 클라이언트에서 갱신된다.
- [ ] 역할 계승이 일어난 그 밤에는 새 역할 능력을 사용할 수 없고 다음 밤부터 사용할 수 있다.
- [ ] 전환된 도둑은 최종 진영의 승리 인원과 결과에 반영된다.

## 살인귀

- [ ] 살인귀는 마녀 명단에 포함되지 않고 이방인으로 표시된다.
- [ ] 첫날에는 무작위 주민 위장 도구를 들고 시작한다.
- [ ] 둘째 날부터 보유한 위장 도구가 2종 이상이면 밤 준비에서 도구를 선택할 수 있다.
- [ ] 살인귀가 사망자가 떨어뜨린 주민 위장 도구를 E키로 회수해 보유 목록에 추가할 수 있다.
- [ ] 살인귀는 마녀 살해 담당 투표와 관계없이 매 밤 F키 직접 살해를 한 번 사용할 수 있다.
- [ ] 살인귀는 주민, 마녀, 이방인 중 자기 자신을 제외한 생존자를 살해 대상으로 지정할 수 있다.
- [ ] 살인귀 직접 살해는 기존 직접 살해와 같은 시전 시간, 거리 검증, 행동 불가·감금 검증을 사용한다.
- [ ] 살인귀가 기절하거나 감금되면 그 밤의 미사용 살해권이 다른 사람에게 이전되지 않는다.
- [ ] 살인귀의 직접 살해는 의원 보호에 막힌다.
- [ ] 살인귀와 마녀가 서로 다른 대상을 지정하면 밤 결과에 두 사망자가 각각 한 번만 기록된다.
- [ ] 살인귀와 마녀가 같은 대상을 지정하면 중복 사망과 중복 도구 드롭이 발생하지 않는다.
- [ ] 마녀와 살인귀가 서로를 지정한 경우 양쪽의 확정된 밤 행동 처리 순서를 확인한다.
- [ ] 살인귀가 살아 있는 동안 주민 및 마녀의 일반 승리가 확정되지 않는다.
- [ ] 살인귀 혼자 생존하면 살인귀 개인 승리로 경기가 종료된다.
- [ ] 살인귀 1명과 주민 1명만 생존하면 살인귀 개인 승리로 경기가 종료된다.
- [ ] 살인귀 1명과 마녀 1명만 생존하면 마녀 승리가 확정되지 않고 최종 결투에 진입한다.
- [ ] 도둑이 사망한 살인귀의 도구를 훔치면 살인귀와 이방인 진영을 계승하고 다음 밤부터 매일 살해할 수 있다.

## 살인귀 대 마녀 최종 결투

- [ ] 아침 투표 또는 밤 행동으로 살인귀 1명과 마녀 1명만 남으면 해당 결과 화면을 먼저 표시한 뒤 최종 결투로 전환한다.
- [ ] 최종 결투 진입 직후 중앙 전환 화면에 `최종 결투`, 결투 규칙과 5초 카운트다운이 모든 클라이언트에 같은 서버 시간 기준으로 표시된다.
- [ ] 준비 연출 동안 두 참가자는 각자 소유 집 앞에 배치되지만 이동·공격할 수 없고 무기도 표시되지 않는다.
- [ ] 카운트다운이 끝나는 순간 중앙 전환 화면이 닫히고 두 참가자의 이동, 기본 무기와 피격 판정이 함께 활성화된다.
- [ ] 기존 최종 결투 전역 알림이 중앙 전환 화면과 중복되어 표시되지 않는다.
- [ ] 아침/밤 타이머가 중단되고 결투 중에는 다음 일반 페이즈로 자동 진행하지 않는다.
- [ ] 두 참가자의 영체가 각자 소유 집의 FrontDoorOutsidePoint로 이동하고 CurrentHouseId가 외부(-1)로 판정된다.
- [ ] 두 참가자는 결투 진입 직전 들고 있던 위장 도구를 그대로 든 채 이동과 기본 무기 공격만 사용할 수 있다.
- [ ] F키 직업 능력, E키 정문·뒷문, 드롭 도구 습득, 저주 인형 상호작용, 집 전등이 모두 차단된다.
- [ ] 결투 참가자가 아닌 생존·사망 영체는 이동과 공격을 포함한 조작이 비활성화된다.
- [ ] 결투 시작 시 이전 피격 누적과 피격 잠금이 사라지고 양쪽 체력이 각각 3으로 초기화된다.
- [ ] 야외에서 참가자가 상대 참가자를 공격하면 한 번의 유효 공격당 체력이 1만 감소한다.
- [ ] 결투 참가자 외의 야외 피격은 기존 규칙처럼 체력 감소나 최종 사망으로 이어지지 않는다.
- [ ] 세 번째 유효 피격을 받은 참가자는 즉시 최종 사망하고 일반 제압 또는 감금으로 전환되지 않는다.
- [ ] 살인귀가 생존하면 `살인귀 승리 / 살인귀 혼자 살아남았습니다.` 결과가 열리고, 마녀가 생존하면 `마녀 승리 / 모든 주민이 제거되었습니다.` 결과가 열린다.
- [ ] 결투 중 한 참가자가 연결 해제되면 남은 참가자 역할에 맞는 승리 결과가 즉시 열린다.
- [ ] 순교자 추방으로 동시에 1대1 구도가 만들어져도 순교자 개인 승리가 최종 결투보다 우선한다.

## 순교자

- [ ] 순교자는 경기 시작 시 주민 전체 도구 풀에서 무작위 도구 하나를 위장용으로 받는다.
- [ ] 순교자가 받은 도구의 외형, 기본 공격, 사망 시 드롭은 정상 동작하지만 해당 주민 직업 능력은 사용할 수 없다.
- [ ] 도둑이 사망한 순교자의 도구를 훔치면 도구 외형이 아니라 순교자 역할과 이방인 진영을 계승한다.
- [ ] 순교자가 아침 투표의 단독 최다 득표자로 실제 추방되면 개인 승리가 확정된다.
- [ ] 순교자 추방 시 아침 투표 결과를 먼저 표시한 뒤 게임 결과로 전환한다.
- [ ] 순교자가 동률, 기권 우세 또는 무투표로 추방되지 않으면 승리하지 않는다.
- [ ] 순교자가 직접 살해, 독살, 저주 인형, 퇴마사 처형 또는 연결 종료로 사라지면 승리하지 않는다.
- [ ] 순교자 승리 결과 화면에 개인 승리자의 이름이 표시된다.
- [ ] 순교자 본인에게는 승리, 나머지 플레이어에게는 패배로 표시된다.

## 승리 판정과 결과 화면

- [ ] 생존 마녀 0명, 생존 주민 1명 이상, 미전환 도둑 생존 상태에서 주민 승리가 확정되고 도둑은 함께 승리하지 않는다.
- [ ] 생존 마녀 1명, 생존 주민 1명, 미전환 도둑 1명일 때 마녀 승리가 확정되지 않는다.
- [ ] 생존 마녀 1명과 미전환 도둑 1명만 남으면 마녀 승리가 확정된다.
- [ ] 미전환 도둑 1명과 생존 주민 1명만 남으면 주민 승리가 확정되고 도둑 개인은 패배한다.
- [ ] 미전환 도둑 한 명 또는 여러 명만 생존하면 살아 있는 도둑 전원의 공동 승리로 경기가 종료된다.
- [ ] 생존 마녀 1명, 생존 주민 1명, 순교자 1명일 때 마녀 승리가 확정되지 않는다.
- [ ] 생존 마녀 1명, 미전환 도둑 1명, 순교자 1명일 때 마녀 승리가 확정되지 않는다.
- [ ] 미전환 도둑과 순교자는 마녀 동률 판정 인원으로만 주민 쪽에 포함되고, 실제 진영과 결과 화면 승패는 이방인 상태를 유지한다.
- [ ] 도둑이 주민 역할을 계승한 뒤에는 생존 주민 수에 포함된다.
- [ ] 도둑이 마녀 역할을 계승한 뒤에는 생존 마녀 수와 결과 화면의 마녀 명단에 포함된다.
- [ ] 승리 확정이 투표 결과 또는 밤 결과 표시를 건너뛰지 않고 결과 페이즈 뒤에 적용된다.
- [ ] 주민 결과 화면에 `주민 승리 / 모든 마녀가 제거되었습니다.`가 표시되고, 마녀 결과 화면에 `마녀 승리 / 모든 주민이 제거되었습니다.`가 표시된다.
- [ ] 결과 화면의 마녀 명단에 사망자를 포함한 최종 마녀 진영 구성원이 표시된다.
- [ ] 결과 화면에 각 클라이언트의 승리/패배, 최종 진영, 최종 역할이 표시된다.
- [ ] 미전환 도둑은 주민 또는 마녀 진영 승리 시 `패배 · 이방인 · 도둑`으로 표시된다.
- [ ] 주민 역할을 계승한 도둑과 마녀 역할을 계승한 도둑의 최종 결과가 새 진영 기준으로 표시된다.
- [ ] 살인귀 또는 순교자 승리 시 개인 승리자 이름과 본인의 승패가 올바르게 표시된다.
- [ ] 도둑 공동 승리 시 `도둑 승리 / 도둑들만 살아남았습니다.`와 생존 도둑 전원의 이름이 표시되고 해당 도둑들만 승리로 표시된다.

## 역할 UI 텍스트

- [ ] 상단 상태 UI와 프리팹 기본값이 `직업`, `생존`, `N일차`, `대화`, `아침 투표`의 최신 한글 문구로 표시된다.
- [ ] 로비, 상단 상태, 투표, 채팅, 영체 이름표와 집주인 이름표의 TMP가 현재 Pretendard SDF를 사용하고 글자 아래 수평선이나 깨진 잔상이 나타나지 않는다.
- [ ] 한글과 영문 닉네임을 함께 표시해도 폰트가 흐려지거나 fallback용 하위 TMP 오브젝트가 불필요하게 생성되지 않는다.
- [ ] 내통자 행동 모드 알림에 `스파이` 또는 `시민 능력`이 남지 않고 `내통자`와 `주민 능력`으로 표시된다.
- [ ] 모든 주민 역할의 좌상단 능력 설명이 명시적인 두 줄로 표시되고 잘리지 않는다.
- [ ] 모든 마녀 역할의 좌상단 능력 설명이 명시적인 두 줄로 표시되고 잘리지 않는다.
- [ ] 도둑, 살인귀, 순교자의 좌상단 능력 설명이 명시적인 두 줄로 표시되고 잘리지 않는다.
- [ ] 도둑이 역할을 계승하면 좌상단 역할명과 두 줄 설명이 계승 역할 기준으로 즉시 갱신된다.

## 야간 직무 최소 구현

- [ ] 직업 행동의 중앙 원형 커서 게이지는 기존 프리팹 크기의 75%, 야간 직무 게이지는 50%로 표시되고 두 행동 사이를 전환하면 각 크기가 즉시 적용된다.
- [ ] 밤 준비마다 생존 주민에게 활성화된 NightDutyPoint 중 서로 다른 두 지점이 무작위로 배정되고 상시 직무 UI에 표시된다.
- [ ] 직무 배정 시 `오늘 밤 직무:` 하단 알림은 표시되지 않는다.
- [ ] 마녀, 미전환 도둑, 살인귀, 순교자에게는 야간 직무가 배정되지 않는다.
- [ ] 직무 지점 수가 전체 배정 수 이상이면 같은 밤에 플레이어 사이에서도 서로 다른 지점이 배정된다.
- [ ] 활성 직무 지점이 두 개보다 적은 테스트 맵에서는 중복 직무를 만들지 않고 사용 가능한 서로 다른 지점만 배정된다.
- [ ] 지정된 전용 Collider를 카메라로 조준하고 F키를 설정 시간 동안 누르면 해당 직무가 한 번만 완료된다.
- [ ] 첫 번째 직무를 완료한 뒤 두 번째 직무도 계속 조준 및 F키 수행이 가능하다.
- [ ] 상시 직무 UI가 두 직무명을 표시하고 완료에 따라 상태 아이콘과 진행도가 0/2, 1/2, 2/2로 갱신된다.
- [ ] 첫날 밤에는 이전 직무 기록이 없으므로 마을 안정도 100%와 개인 직무 실패 확률 0%로 시작한다.
- [ ] 집에 속한 직무는 `닉네임의 침대 프레임 점검`처럼 해당 집주인의 닉네임을 포함한다.
- [ ] 광장 우물처럼 집주인이 없는 공용 직무는 기존 직무명만 표시된다.
- [ ] 다른 직무 지점, 다른 집의 동일 번호 지점, 거리 밖 지점에 대한 완료 요청은 서버에서 거절된다.
- [ ] 사망, 기절, 감금, NightAction 종료 뒤 도착한 완료 요청은 서버에서 거절된다.
- [ ] 직무 완료 여부와 해당 밤의 주민 직업 능력 사용 여부는 서로 소비하지 않는다.
- [ ] 다음 밤에는 이전 완료 상태가 초기화되고 새 직무가 다시 배정된다.
- [ ] 활성 NightDutyPoint가 하나도 없으면 예외 없이 배정을 건너뛰고 서버 경고 로그가 남는다.
- [ ] 기존 집 전등과 별도의 Collider에 직무 지점을 둔 경우 F키 입력이 전등 상호작용과 중복 처리되지 않는다.
- [ ] 마녀, 저주술사, 내통자, 잠입자는 실제 직무를 배정받지 않지만 어느 활성 NightDutyPoint에서든 주민과 같은 F키 진행 시간으로 가짜 직무를 수행할 수 있다.
- [ ] 살해 담당 마녀에게는 가짜 직무 상호작용과 진행 UI가 나타나지 않으며, 직무 지점과 살해 대상이 겹쳐도 살해 행동이 우선 처리된다.
- [ ] 살해 담당 마녀가 조작된 가짜 직무 완료 요청을 보내도 서버가 거절하고 가짜 직무 사용 횟수와 팀 살해권을 소비하지 않는다.
- [ ] 마녀 한 명이 한 밤에 가짜 직무를 두 번 수행하면 세 번째 지점에서는 직무 진행이 시작되지 않는다.
- [ ] 가짜 직무 사용 횟수는 다음 밤에 0/2로 초기화되고, 중간 상태 재동기화 뒤에도 서버 사용 횟수와 일치한다.
- [ ] 가짜 직무는 주민의 실제 직무 완료 상태와 마을 안정도 산정값을 변경하지 않는다.
- [ ] 미전환 도둑, 살인귀, 순교자는 가짜 직무를 수행할 수 없다.
- [ ] 거리 밖, 사망, 기절, 감금, NightAction 종료 뒤 도착한 가짜 직무 요청은 서버에서 거절된다.
- [ ] 밤 종료 시 마을 안정도가 `완료된 주민 직무 수 / 배정된 주민 직무 수 × 100`으로 정산되고 모든 클라이언트 UI에 같은 값이 표시된다.
- [ ] 배정된 주민 직무가 하나도 없으면 마을 안정도는 100%로 정산된다.
- [ ] 마녀 플레이어에게 실제 주민 직무 행은 표시되지 않고 `마을 안정도 N%`만 표시된다.
- [ ] 주민, 마녀, 이방인에게 표시되는 마을 안정도 백분율이 항상 동일하고, 직무가 없는 마녀와 이방인에게도 안정도 패널이 표시된다.
- [ ] 개인별 미완료 직무가 0개, 1개, 2개일 때 다음 밤의 직무 실패 확률이 각각 0%, 25%, 50%가 된다.
- [ ] 개인별 미완료 수는 매일 새 결과로 덮어써서 이틀 이상 연속 실패해도 50%를 넘겨 누적되지 않는다.
- [ ] 안정도 실패 확률은 `(100 - 안정도) × 0.25%`이며 0%에서 최대 25%가 된다.
- [ ] 최종 능력 실패 확률은 `1 - (1 - 직무 실패 확률) × (1 - 안정도 실패 확률)`로 계산된다.
- [ ] 안정도와 개인 미완료 결과는 해당 밤 도중 바뀌지 않고 다음 밤 능력 판정부터 적용된다.
- [ ] 서버 검증을 모두 통과한 실제 주민 능력이 확률 판정에 실패하면 효과가 발생하지 않고 그날 사용 기회가 소비된다.
- [ ] 능력 실패 시 본인에게만 `직무 미완료와 마을의 불안정 영향으로 능력이 실패했습니다.`와 `오늘은 이 능력을 다시 사용할 수 없습니다.`가 두 줄로 표시된다.
- [ ] 퇴마사가 확률 판정에 실패하면 대상은 생존하지만 게임 전체 1회 퇴마 횟수와 그날 행동 기회가 모두 소비된다.
- [ ] 잘못된 대상, 거리 이탈, 기절, 감금, 단계 변경 및 늦은 요청으로 서버가 행동을 거절하면 실패 확률을 굴리지 않고 사용 기회도 소비하지 않는다.
- [ ] 의원, 집행관, 퇴마사, 수사관, 검시관, 영매사, 사냥꾼, 장의사와 실제 도구를 받은 행상인에게만 주민 능력 실패 판정이 적용된다.
- [ ] 마녀 진영의 위장 주민 행동, 능력 없는 행상인 도구, 주정뱅이 취침 선택, 횃불, 직무, 저주 인형, 미전환 도둑과 이방인 행동에는 주민 능력 실패 판정이 적용되지 않는다.

## 마을 안정도 야간 시야 효과

- [ ] 야간에는 각 클라이언트의 본인 집 닉네임 앞에 `▶`가 붙고, 닉네임이 본인 진영 색상과 굵은 글씨로 표시된다.
- [ ] 안정도 25~49%에서는 주민·이방인에게 타인 집 이름이 50% 밝기로 표시되고 본인 집 이름은 정상 밝기를 유지한다.
- [ ] 안정도 1~24%에서는 주민·이방인에게 본인 집 이름과 사망 상태만 표시되고 타인 집 이름과 사망 상태는 숨겨진다.
- [ ] 안정도 0%에서는 주민·이방인에게 본인 집을 포함한 모든 집 이름과 사망 상태가 숨겨진다.
- [ ] 마녀와 사망 관전자는 안정도와 관계없이 모든 집 이름을 보며, 아침 투표·게임 결과에는 모든 집 이름이 정상 상태로 복구된다.

- [ ] 안정도 75~100%는 `안정`, 50~74%는 `보통`, 25~49%는 `불안`, 0~24%는 `붕괴`로 모든 클라이언트 UI에 동일하게 표시된다.
- [ ] 주민과 이방인은 안정 상태에서 기본 야간 안개 밀도의 0.9배가 적용되어 기존보다 시야가 소폭 좋아진다.
- [ ] 주민과 이방인은 보통 상태에서 기존 야간 안개값을 그대로 사용한다.
- [ ] 주민과 이방인은 불안 상태에서 기본 야간 안개 밀도의 1.25배가 적용되어 시야가 감소한다.
- [ ] 주민과 이방인은 붕괴 상태에서 기본 야간 안개 밀도의 1.5배가 적용되어 시야가 크게 감소한다.
- [ ] 마녀 진영은 안정도 단계와 관계없이 기본 야간 안개값을 유지하고 UI에는 `시야 영향 없음`이 표시된다.
- [ ] 내통자가 주민 위장 능력을 사용해도 실제 마녀 진영이므로 안정도 시야 패널티를 받지 않는다.
- [ ] 미전환 도둑, 살인귀와 순교자는 주민과 동일한 안정도 시야 효과를 받는다.
- [ ] 도둑이 주민·마녀·이방인 역할을 계승하면 갱신된 최종 진영 기준으로 야간 시야 효과가 즉시 다시 적용된다.
- [ ] 안정도 시야 효과는 밤 준비, 밤 행동과 밤 결과에서만 적용되고 아침 투표·게임 결과에서는 원래 카메라와 안개 설정으로 복구된다.
- [ ] 한 클라이언트의 진영과 안정도 시야 설정이 같은 프로세스의 다른 소유자 또는 다른 클라이언트 카메라 설정에 영향을 주지 않는다.
- [ ] 안정도 단계가 달라도 주민·마녀의 직업 행동, 가짜 직무와 살해 행동 시전 시간은 기존 값과 동일하다.

## 의원과 최종 사망 처리

- [ ] 의원 보호는 일반 직접 살해를 막는다.
- [ ] 의원 보호는 마녀의 독살을 막는다.
- [ ] 의원 보호는 퇴마사 처형을 막지 못한다.
- [ ] 의원 보호는 저주 인형 살해를 막지 못한다.
- [ ] 같은 밤의 독, 저주, 직접 살해 결과가 서버에서 한 번만 확정되고 중복 사망 또는 중복 도구 드롭이 없다.
- [ ] 사망 결과 UI가 최대 두 명의 사망자를 표시하되 모든 야간 사망 원인을 `살해당했습니다.`로 통일한다.
- [ ] 공개 사망 문구를 통일해도 검시관에게만 제공되는 직접 살해, 독살, 저주 인형, 영체 소멸 사인 데이터는 유지된다.
- [ ] 아침 투표로 추방된 플레이어의 도구는 기존 ToolDropPoint 위치에 생성되고 육체는 모든 클라이언트에서 제거된다.
- [ ] 추방자의 육체가 제거된 뒤 검시관과 영매사는 해당 플레이어를 상호작용 대상으로 선택할 수 없다.
- [ ] 퇴마로 사망한 플레이어의 육체는 집에 남고 검시관 조사 결과에 `사인: 영체 소멸`이 표시된다.
- [ ] 퇴마로 영체가 소멸한 플레이어에게 영매사 능력을 사용하면 서버가 `영체가 소멸한 사망자와는 교신할 수 없습니다.`로 거절하고 행동 기회를 소비하지 않는다.

## 주정뱅이 사망 연출

- [ ] 주정뱅이가 선택한 외부 벤치에서 정상적으로 잠든다.
- [ ] 외부에서 사망한 주정뱅이의 육체가 해당 집의 DrunkardDeathPoint로 이동한 뒤 사망 연출을 시작한다.
- [ ] 주정뱅이의 드롭 도구가 이동된 육체의 ToolDropPoint에서 바닥에 자연스럽게 생성된다.
- [ ] DrunkardDeathPoint가 없는 구형 집에서는 예외 없이 기존 육체 위치를 사용하고 경고 로그만 남긴다.
- [ ] 자기 집에서 사망한 일반 플레이어의 기존 SpiritPoint 사망 연출과 ToolDropPoint에는 변화가 없다.

## 음성 및 관전 회귀

- [ ] 횃불이 과반수에 도달하기 전에는 아직 사용하지 않은 생존자가 자기 집 횃불을 정상적으로 켤 수 있다.
- [ ] 횃불이 과반수에 도달해 마을 전체 점등 효과가 활성화되면 아직 사용하지 않은 플레이어의 횃불 조준 표시가 더 이상 나타나지 않는다.
- [ ] 과반수 달성과 거의 동시에 여러 클라이언트가 횃불 요청을 보내도 과반수 이후 처리된 요청은 서버에서 거절되고 해당 플레이어의 1회 사용권이 보존된다.
- [ ] 과반수 이후 거절된 플레이어가 다음 경기에서 횃불을 정상적으로 사용할 수 있다.

- [ ] 밤에 횃불을 직접 켠 생존자들만 같은 위치 기반 음성 채널에 참가하고 서로의 거리·방향에 맞게 들린다.
- [ ] 횃불을 켜지 않은 생존자는 마을 전체 점등 후에도 야간 위치 기반 음성을 송수신하지 못한다.
- [ ] 횃불 사용자 목록이 늦게 동기화된 클라이언트도 즉시 올바른 야간 음성 채널 상태로 갱신된다.
- [ ] 아침 생존자 그룹 음성과 밤 횃불 사용자 위치 기반 음성이 페이즈 전환마다 올바르게 참가/이탈한다.
- [x] 영매사와 선택된 사망자만 비공개 교신 채널에 참가한다. (MPPM 음성 교신 확인 완료)
- [ ] 영매사와 사망자가 전용 채널 참가 직후 서로 말할 수 있고, 일시적인 채널 참가·송신 모드 갱신 실패가 발생해도 재시도 후 교신이 복구된다.
- [ ] 횃불 음성 채널에도 참가한 영매사는 동일 상대의 위치 기반 음성을 중복해서 듣지 않으면서 영매사 전용 채널 음성은 정상적으로 듣는다.
- [ ] 여러 영매사가 같은 사망자와 교신할 때 모든 영매사와 해당 사망자가 서로의 음성을 송수신한다.
- [ ] 사망, 감금, 연결 종료 시 해당 음성 채널 상태가 정리된다.
- [ ] 사망 직후 제한 관전과 제한 해제 후 자유 관전이 호스트와 클라이언트에서 동일하다.
- [ ] 두 번째 경기에서 이전 경기의 Vivox 채널, 음소거, 교신 대상 상태가 남지 않는다.

## ESC 음성·그래픽 설정과 로컬 음소거

- [ ] ESC 도움말 상단에 `조작법`, `게임 규칙`, `음성`, `그래픽` 네 탭이 한 줄에 겹치지 않고 표시된다.
- [ ] 음성 탭에는 게임 음량, 음성 채팅 음량, 마이크, 음성 수신 설정만 표시되고 그래픽 탭에는 마우스 감도, 화면 모드, 해상도, 그래픽 품질, FPS 제한만 표시된다.
- [ ] 최대 13명 경기에서 로컬 플레이어를 제외한 12명의 닉네임과 음성 연결 상태, 음소거 버튼이 음성 탭의 프레임 안에 모두 표시된다.
- [ ] 특정 참가자를 음소거하면 같은 참가자가 아침, 횃불 야간 채널, 영매사 교신 채널 중 둘 이상에 참가해도 모든 채널에서 로컬 음성이 들리지 않는다.
- [ ] 음소거한 참가자가 채널을 나갔다가 다시 참가하거나 아침·밤 페이즈가 전환되어도 해당 경기 동안 로컬 음소거가 유지된다.
- [ ] `음소거 해제`를 누르면 사용자 음소거만 해제되고, 영매사 교신 중 중복 음성을 막기 위한 기존 자동 음소거는 유지된다.
- [ ] 다른 클라이언트가 한 참가자를 로컬 음소거해도 호스트와 나머지 클라이언트의 음성 수신 상태에는 영향을 주지 않는다.
- [ ] 참가자가 연결 해제되면 음성 탭 목록에서 제거되고, 다음 경기에서는 이전 경기의 사용자 음소거 상태가 남지 않는다.

## 네트워크 상태 재동기화

- [ ] 호스트가 Relay 방을 생성하면 특정 지역을 고정 요청하지 않고 자동 선택된 실제 Relay 지역이 로그와 완료 상태에 표시된다.
- [ ] 호스트가 게임을 시작해도 모든 배정 대상 클라이언트가 자기 직업 정보를 수신·적용하기 전에는 첫 아침 투표 페이즈가 시작되지 않는다.
- [ ] 먼저 직업을 받은 클라이언트는 다른 플레이어를 기다리는 동안 `준비 중` 상태를 유지하고 아침·밤 타이머가 진행되지 않는다.
- [ ] 고지연 클라이언트가 다른 플레이어보다 늦게 GameScene과 MatchManager를 Spawn해도 역할 재요청 후 준비 ACK를 보내고 전원 확인 시 정상 시작된다.
- [ ] 역할 수신 ACK가 중복 도착해도 준비 인원 수가 중복 증가하지 않고 첫 페이즈가 한 번만 시작된다.
- [ ] 역할을 받은 뒤 최초 ACK가 지연되어도 `MatchPhase.None` 동안 1초 간격 재확인으로 자동 복구된다.
- [ ] 역할 배정 대기 중 실제로 연결 해제된 클라이언트는 준비 대상에서 제거되고 남은 배정 인원이 모두 확인되면 경기가 시작된다.
- [ ] 이전 경기나 다른 마을 배정 토큰의 늦은 ACK는 새 경기 준비 확인으로 인정되지 않는다.
- [ ] 고지연 클라이언트가 게임 씬 진입 후 10초 안에 직업 정보를 받지 못해도 연결이 유지되면 `직업 배정 중`에서 자동으로 복구된다.
- [ ] 직업 정보 수신이 10초 이상 지연되면 경고 로그는 한 번만 남고, 이후 재요청이 1초 간격으로 계속된다.
- [ ] 생성이 늦은 NetworkObject를 대상으로 먼저 도착한 메시지가 30초 안에는 폐기되지 않고 객체 생성 후 정상 처리된다.
- [ ] 마녀 클라이언트가 로컬 상태를 늦게 요청하거나 재동기화해도 현재 밤 살해 담당자 표시와 살해 권한이 서버 상태와 일치한다.
- [ ] 현재 살해 담당자가 연결 해제되면 남은 마녀 전원에게 미지정 상태가 동기화되고 이전 담당자는 더 이상 살해 행동을 할 수 없다.
- [ ] 서버 재동기화와 페이즈 전환 중 NGO 권한 위반, 잘못된 RPC 대상, 중복 RPC 호출 예외가 발생하지 않는다.
- [ ] 호스트가 로비에서 방을 나가면 참가 클라이언트 전원이 연결 종료 안내를 받고 로그인 화면으로 복구된다.
- [ ] 호스트가 방을 나간 직후 같은 프로세스에서 새 Relay 방을 생성해도 `NetworkManager.StartHost` 예외가 발생하지 않는다.
- [ ] 호스트가 사라진 방에서 복구된 클라이언트가 같은 프로세스에서 다른 방 코드로 참가해도 `NetworkManager.StartClient` 예외가 발생하지 않는다.
- [ ] 일반 클라이언트가 자발적으로 방을 나간 뒤 새 방 생성과 다른 방 참가를 각각 다시 수행할 수 있다.
- [ ] 게임 결과 후 같은 Relay 방의 로비로 돌아가 두 번째 게임을 시작해도 기존 `NetworkManager`, `LobbyRoomManager`, 매치 오브젝트가 중복되지 않는다.
- [ ] 게임 결과 후 로비로 돌아와 방을 나간 다음 새 방 생성·참가를 해도 이전 Relay 코드와 콜백 상태가 남지 않는다.
- [ ] 연결 종료 버튼 직후 생성·참가 버튼을 빠르게 눌러도 이전 NGO Shutdown 완료 전 `StartHost` 또는 `StartClient`가 호출되지 않는다.
- [ ] 연결 종료 중 로그인 화면에 `네트워크 연결을 종료하는 중입니다.`가 표시되고 닉네임, 코드, 생성, 참가 입력이 비활성화된다.
- [ ] NGO Shutdown이 끝난 뒤 `로비에서 나왔습니다.`로 바뀌며 생성·참가 입력이 다시 활성화된다.

## 피격 중 직업 행동

- [ ] 주민이 집 안에서 직업 능력 게이지를 채우는 중 첫 피격을 받으면 게이지와 진행 UI가 즉시 초기화된다.
- [ ] 마녀가 집 안에서 살해 또는 위장 능력 게이지를 채우는 중 첫 피격을 받으면 동일하게 초기화된다.
- [ ] 집 밖에서 직업 능력 게이지를 채우는 중 피격되면 진영과 관계없이 게이지가 초기화된다.
- [ ] 피격되면 진행 중인 직업 능력과 야간 직무 게이지가 모두 취소되지만, 이미 완료한 직무 상태는 변경되지 않는다.
- [ ] 능력 완료 요청이 이미 서버로 전송된 뒤 도착한 피격 연출이 완료 요청을 중복 전송하거나 클라이언트를 대기 상태에 고정하지 않는다.

## 피격 후 문 잠금과 야간 체력 유지

- [ ] 집 안에서 유효한 피격을 받은 플레이어가 2초 동안 정문과 잠입자 뒷문으로 나갈 수 없다.
- [ ] 집 밖에서 유효한 피격을 받은 플레이어가 2초 동안 정문과 잠입자 뒷문으로 들어갈 수 없다.
- [ ] 문 잠금 중 실제 문 범위에서 E키를 누르면 본인에게만 `피격 직후에는 잠시 문을 이용할 수 없습니다.`가 표시된다.
- [ ] 피격 직후 로컬 잠금 동기화보다 문 요청이 먼저 서버에 도착해도 서버가 이동을 거절하고 같은 안내를 전송한다.
- [ ] 잠금 중 다시 피격되면 마지막으로 인정된 피격 시점부터 2초로 문 잠금이 연장된다.
- [ ] 피격 문 잠금은 문 사용만 차단하며 떨어진 도구 습득과 저주 인형 설치·습득 E키 상호작용은 차단하지 않는다.
- [ ] 집 안에서 한 번 또는 두 번 피격된 뒤 문으로 나갔다 다시 들어와도 남은 HP가 회복되지 않는다.
- [ ] 같은 밤에 서로 다른 집을 이동해도 기존에 잃은 HP가 유지된다.
- [ ] 다음 날 NightAction이 시작되면 생존 영체의 HP가 3으로 초기화된다.
- [ ] 집 안에서 3회 피격되어 기절·감금된 경우의 기존 패배 처리와 HP 초기화는 그대로 유지된다.
- [ ] 주정뱅이의 집 밖 3회 피격과 최종 결투 시작 시 HP 초기화·3회 피격 규칙은 그대로 유지된다.

## 제압 상태와 해제 후 무적

- [ ] 집주인이 자기 집 안에서 3회 피격되면 별도 툴팁 없이 5초 동안 제압된다.
- [ ] 주정뱅이가 집 밖에서 3회 피격되면 동일한 제압 상태가 적용된다.
- [ ] 제압 시작·성공·해제 시 제압 당사자와 공격자에게 별도의 제압 툴팁이 표시되지 않는다.
- [ ] 제압 중인 영체를 계속 공격해도 HP 감소, 피격 연출, 피격음, 문 잠금 연장 및 추가 제압이 발생하지 않는다.
- [ ] 제압 중인 영체는 모든 클라이언트에서 청회색으로 표시되고 제압이 끝나면 원래 색상으로 돌아온다.
- [ ] 제압 당사자의 기존 피격 화면 Volume이 제압 시간 동안 약하게 유지되고 해제 시 사라진다.
- [ ] 제압 해제 후 1.5초 동안 공격을 받아도 HP 감소와 피격 피드백이 발생하지 않는다.
- [ ] 해제 후 1.5초가 지나면 새로운 공격이 정상적으로 인정된다.
- [ ] NightAction이 종료되거나 새 밤, 최종 결투가 시작되면 남아 있던 제압 및 무적 상태가 정리된다.
- [ ] 타인의 집에서 3회 피격되어 감금되는 기존 처리에는 제압 색상과 해제 후 무적이 잘못 적용되지 않는다.

## 본인 영체 내구도 UI

- [ ] NightAction과 최종 결투에서만 아침의 대화·투표 탭 위치에 OArielG 하트 3칸이 표시된다.
- [ ] 아침에는 대화·투표 탭이 표시되고 하트 패널은 숨겨지며, 밤 행동에는 탭이 숨겨지고 같은 위치에 하트 패널이 표시된다.
- [ ] 다른 클라이언트의 피격 여부와 관계없이 각 클라이언트에는 본인 영체의 하트만 갱신된다.
- [ ] 자기 집과 타인의 집에서 유효한 피격을 받을 때마다 하트가 3칸, 2칸, 1칸 순서로 줄어든다.
- [ ] 소모된 체력 칸은 반투명한 붉은 하트가 아니라 `ui-small-icons_1`의 탁한 하트 Sprite로 교체되고, 남은 체력 칸은 `ui-small-icons_0`의 붉은 하트를 유지한다.
- [ ] 일반 영체가 집 밖에서 피격될 때는 현재 규칙대로 하트가 줄지 않고, 주정뱅이만 집 밖 피격 시 하트가 줄어든다.
- [ ] 자기 집 또는 주정뱅이의 집 밖에서 3회 피격되어 제압되면 세 하트가 모두 흐리게 표시되고, 제압 해제 후 3칸으로 복구된다.
- [ ] 타인의 집에서 3회 피격되어 감금되면 세 하트가 모두 흐리게 표시된다.
- [ ] 제압 중 추가 공격과 제압 해제 후 무적 시간의 공격에는 하트 표시가 변하지 않는다.
- [ ] 같은 밤에 집을 드나들거나 다른 집으로 이동해도 줄어든 하트가 유지되고, 다음 NightAction 시작 시 3칸으로 초기화된다.
- [ ] 아침 투표, 밤 준비, 밤 결과, 게임 결과 및 사망 상태에서는 영체 하트 패널이 표시되지 않는다.
- [ ] 최종 결투에서는 피격마다 하트가 한 칸씩 줄고 마지막 하트가 소진되면 결과 화면으로 전환된다.

## 출품용 도움말과 조작 안내

- [ ] 로비의 `게임 방법` 버튼으로 도움말이 열리고 기존 로그인·방·설정 UI보다 앞에 표시된다.
- [ ] 로비와 인게임 도움말은 별도 Canvas 정렬로 모든 기존 UI보다 앞에 표시되고, 뒤쪽 버튼을 클릭할 수 없다.
- [ ] 로비 도움말의 `조작법`과 `게임 규칙` 탭이 서로 전환되며 선택 중인 탭 버튼은 비활성화된다.
- [ ] 로비 도움말은 `계속하기` 버튼과 ESC 모두로 닫힌다.
- [ ] 인게임에서 텍스트 채팅을 입력하지 않는 상태로 ESC를 누르면 도움말이 열린다.
- [ ] 인게임 도움말이 열린 동안 이동, 점프, 시점 회전, 기본 공격, 문 출입, 도구·인형 상호작용, 직업 행동, 야간 직무와 횃불 입력이 실행되지 않는다.
- [ ] 인게임 도움말을 닫으면 도움말을 열기 전 활성화되어 있던 플레이어 조작 컴포넌트만 복구된다.
- [ ] NightAction과 최종 결투에서 도움말을 닫은 다음 프레임에 커서가 다시 잠기고 시점 조작이 정상 복구된다.
- [ ] 아침 투표와 밤 준비 중 도움말을 닫으면 커서가 UI 조작 상태로 유지된다.
- [ ] 야간 채팅 또는 영매사 채팅 입력 중 ESC를 누르면 채팅 입력만 닫히고 같은 입력으로 도움말이 동시에 열리지 않는다.
- [ ] 도움말이 열린 상태에서 페이즈가 전환되면 도움말이 닫히고 새 페이즈의 커서·입력 상태가 적용된다.
- [ ] 1920×1080 및 창 모드에서 도움말 제목, 두 탭, 본문과 `계속하기` 버튼이 겹치거나 잘리지 않는다.
- [ ] 로비와 인게임의 `게임 규칙` 본문이 도움말 프레임 밖에 그려지지 않고, 마우스 휠과 드래그로 끝 문장까지 세로 스크롤된다.
- [ ] `게임 규칙`을 아래로 스크롤한 뒤 다른 탭으로 이동했다가 다시 열면 규칙 본문이 맨 위에서 시작한다.
- [ ] 로비와 인게임의 `조작법`에 현재 사용하는 E/F/R/Enter/Tab/Alt/ESC 입력이 동일하게 안내된다.
- [ ] 로비와 인게임의 `게임 규칙`에 최대 12명, 통합 아침 투표, 야간 직무·교란 공작, 3회 피격 규칙, 누적 안정도, 횃불, 야간 채팅과 관전 규칙이 동일하게 안내된다.
- [ ] 도움말의 한글이 Pretendard SDF로 표시되고 글자 밑줄·깨짐·fallback 잔상이 나타나지 않는다.
- [ ] 인게임 좌상단 직업명이 주민은 청록색, 마녀는 적색, 이방인은 황록색으로 표시되고 능력 설명 색상은 기존 회색을 유지한다.
- [ ] 도둑이 다른 진영의 도구를 계승하면 좌상단 직업명과 색상이 계승된 직업 및 진영에 맞춰 함께 갱신된다.

## 중도 포기와 게임 결과 역할 공개

- [ ] 인게임에서 ESC 도움말을 열면 `계속하기`와 `로비로 돌아가기` 버튼이 겹치지 않고 함께 표시된다.
- [ ] 도움말의 `로비로 돌아가기`를 누르면 즉시 이탈하지 않고 `로비로 돌아가시겠습니까?`와 `예`, `아니오`가 있는 확인창이 도움말보다 앞에 표시된다.
- [ ] 확인창이 열린 상태에서는 뒤쪽 도움말 탭, 계속하기 및 로비 버튼을 클릭할 수 없다.
- [ ] 확인창에서 `아니오` 또는 ESC를 누르면 확인창만 닫히고 도움말과 현재 네트워크 연결은 유지된다.
- [ ] 일반 클라이언트가 확인창의 `예`를 누르면 본인만 방에서 연결 해제되고 `LobbyScene` 로그인 화면으로 돌아간다.
- [ ] 일반 클라이언트의 중도 이탈 후 호스트와 나머지 클라이언트의 경기는 종료되지 않고 계속 진행된다.
- [ ] 중도 이탈한 클라이언트가 같은 프로세스에서 새 방 생성과 다른 방 참가를 다시 수행할 수 있다.
- [ ] 호스트가 확인창의 `예`를 누르면 경기 결과 페이즈가 아니어도 방 전체가 같은 Relay 로비로 돌아간다.
- [ ] 호스트의 중도 포기 후 로비 플레이어 목록과 게임 설정이 복구되고 두 번째 게임을 정상 시작할 수 있다.
- [ ] 게임 결과 화면의 로비 버튼은 별도의 중도 이탈 확인창 없이 기존처럼 즉시 로비 복귀를 요청한다.
- [ ] 게임 결과 화면에 참가자 전원의 닉네임, 최종 진영, 최종 직업, 생존 여부와 승패가 표시된다.
- [ ] 결과 명단이 화면 높이를 넘으면 스크롤되며 13번째 참가자까지 확인할 수 있다.
- [ ] 마녀·주민·이방인 진영 색상이 결과 명단에 동일하게 적용된다.
- [ ] 도둑이 역할을 계승한 경기에서는 결과 명단에 도둑의 최종 계승 직업과 진영이 표시된다.
- [ ] 주민·마녀·살인귀·순교자·도둑 승리 각각에서 개인 결과와 명단의 승패 판정이 실제 승리 규칙과 일치한다.

## 프레임 제한과 GPU 부하

- [ ] 로비와 인게임에서 VSync가 꺼진 상태에서도 프레임이 기본 60FPS를 크게 초과하지 않는다.
- [ ] 에디터와 Windows 빌드 모두 `Application.targetFrameRate`가 적용되고, 메뉴와 게임 씬에서 GPU 사용률이 무제한 FPS 상태보다 낮아진다.
- [ ] MPPM 클라이언트 여러 개를 실행해도 각 클라이언트가 무제한으로 렌더링하지 않는다.
- [ ] 6인과 13인 마을에서 외곽 나무가 모두 생성된 뒤 프레임이 안정적으로 유지되는지 비교한다.
- [ ] 횃불 과반수 점등 전후의 GPU 프레임 시간을 비교해 그림자 Point Light 부하를 확인한다.

## 마녀 아군 표식과 관전자 역할 정보

- [ ] 생존 마녀는 NightAction 동안 다른 생존 마녀 영체 위에서만 적색 `◆` 표식을 볼 수 있다.
- [ ] 생존 마녀 본인에게는 머리 위 표식이 표시되지 않고, 주민·이방인 클라이언트에는 마녀 표식이 전혀 표시되지 않는다.
- [ ] 횃불 등 기존 야간 신원 공개 조건이 충족되면 마녀 아군은 적색 `◆`와 닉네임이 함께 표시되고, 조건이 없으면 표식만 표시된다.
- [ ] 생존 마녀는 아침 투표창과 마녀 살해 담당 투표창에서 모든 마녀 행을 `번호 · ◆ 닉네임` 순서로 식별할 수 있다.
- [ ] 주민·이방인 클라이언트의 투표창에는 마녀 표식과 다른 플레이어의 직업·진영 정보가 표시되지 않는다.
- [ ] 사망 후 첫 영매사 대상 밤이 끝나 자유 관전으로 전환된 관전자는 아침 투표창에서 생존자와 사망자를 모두 보고, 각 행의 닉네임 아래에서 진영과 직업을 확인할 수 있다.
- [ ] 사망한 관전자는 투표 대상 선택, 기권, 투표 확정 버튼을 사용할 수 없다.
- [ ] 제한 관전 중인 사망자는 투표창과 TAB 현황판에서 다른 플레이어의 진영·직업을 확인할 수 없다.
- [ ] 자유 관전으로 전환된 사망자는 NightAction 동안 본인을 제외한 모든 영체 위에서 닉네임, 진영, 직업을 확인할 수 있다.
- [ ] 자유 관전 전환 직후 새 관전자에게 전체 역할 정보가 누락 없이 도착하고, 지연 환경에서도 일부 행만 빈 상태로 고정되지 않는다.
- [ ] 도둑이 역할과 진영을 계승하면 기존 관전자에게도 변경된 직업·진영이 갱신되고, 마녀 계승 시 생존 마녀 쪽 아군 표식도 갱신된다.
- [ ] 밤 종료와 아침 전환 시 영체 위 마녀·관전자 표식이 모두 사라지고, 다음 NightAction에서 다시 올바르게 표시된다.

## TAB 마을 현황판과 개인 행동 기록

- [ ] 게임 결과를 제외한 경기 중 TAB을 누르고 있는 동안만 현황판이 표시되고, 키를 놓으면 즉시 닫힌다.
- [ ] 현황판을 연 상태에서도 커서 잠금과 이동 입력이 유지되며, 기록 스크롤 외의 게임 입력을 강제로 차단하지 않는다.
- [ ] 아침·야간 채팅 입력 중, ESC 도움말 및 중도 이탈 확인창이 열린 동안에는 TAB 현황판이 표시되지 않는다.
- [ ] 현황판 Canvas 정렬 순서가 일반 인게임 UI보다 높고 ESC 도움말보다 낮아 두 창이 겹치지 않는다.
- [ ] 상단 요약에 일차, 현재 페이즈, 남은 시간, 마을 안정도, 지난밤 직무 수행률, 점등/필요 횃불과 본인 횃불 사용 상태가 표시된다.
- [ ] 능력 성공률이 소수점 둘째 자리까지 표시되고 `1 - (1 - 직무 실패율) × (1 - 안정도 실패율)` 결과와 일치한다.
- [ ] 주민은 직무 1개 미완료 25%, 2개 미완료 최대 50%와 안정도 실패율이 표시되고, 해당 패널티를 받지 않는 마녀·이방인은 두 항목 모두 `영향 없음`으로 표시된다.
- [ ] 제목이 `개인 기록`인 우측 칸에서 능력 성공률과 두 패널티 아래에 본인의 직업 행동 기록이 일차별로 함께 표시되고, 기록이 길어지면 스크롤할 수 있다.
- [ ] 공개 기록에는 투표 결과, 전체 직무 완료 수, 안정도, 점등 수와 공개된 사망자만 기록되며, 밤 기록은 `N일차 밤` 아래에 항목별 한 줄로 표시되고 투표 기록 양식은 유지된다.
- [ ] 공개 기록에 개별 플레이어의 직무 실패, 횃불 사용자, 투표 대상, 사인 및 다른 플레이어의 직업 행동이 노출되지 않는다.
- [ ] 생존 현황에 최대 12명의 닉네임과 생존·사망·추방 여부 및 처리 일차가 표시되며, 본인 행은 진영색과 굵은 글씨로 강조된다. 주민 본인은 표식 없이 표시되고, 이방인 본인은 `●`, 마녀 본인은 `◆`를 사용하며, 생존 마녀 클라이언트에는 다른 마녀도 `◆`와 마녀 진영 색으로 표시된다.
- [ ] 일반 생존자와 제한 관전 중인 사망자는 현황판에서 다른 플레이어의 진영·직업을 볼 수 없고, 자유 관전으로 전환된 사망자만 이를 확인한다.
- [ ] 의원의 보호 대상과 집행관의 감금 대상은 행동을 수행한 본인의 기록에만 남고 실제 피격·보호 성공 여부는 추가로 노출되지 않는다.
- [ ] 수사관 기록에는 내통자의 실제 직업이 아니라 현재 위장 규칙이 적용된 조사 결과가 남는다.
- [ ] 검시관과 사냥꾼의 서버 결과가 해당 일차의 개인 행동 기록에 연결되고 다른 플레이어에게는 보이지 않는다.
- [ ] 영매사의 교신 대상만 기록되며 음성·텍스트 교신 내용은 저장되지 않는다.
- [ ] 주민 능력이 직무·안정도 확률로 실패하면 `능력 실패 · 횟수 소비`로 기록되고 같은 밤 재사용할 수 없다.
- [ ] 행상인의 가짜 도구와 마녀의 위장 행동이 실제 능력 성공으로 오인되지 않도록 각각 구분되어 기록된다.
- [ ] 마녀 팀의 직접 살해·독살·저주 인형 최초 설치는 실제 담당자의 개인 기록과 다른 생존 마녀들의 `마녀 기록`에 함께 남고, 담당자 닉네임·직업·대상·방식이 일치한다.
- [ ] 교란 후보가 배정된 마녀의 좌상단에는 `교란 공작 택1`이 표시되고, 개인 상태에는 교란 공작의 수행 가능·완료 여부만 표시되며 일차별 팀 기록에는 `팀 교란 공작 N회`로 남는다.
- [ ] 마녀 살해 기록은 주민·이방인·사망 관전자에게 전달되지 않으며, 살인귀의 개인 살해 기록도 마녀 팀에 공유되지 않는다.
- [ ] 저주술사의 최초 설치, 이후 인형 습득·설치가 실제 조작한 클라이언트 기록에만 남는다.
- [ ] 주정뱅이가 밤 준비 중 취침 대상을 변경하면 같은 일차 기록은 마지막으로 확정된 대상으로 갱신된다.
- [ ] 도둑이 도구를 계승하면 원 소유자, 최종 계승 직업과 진영이 도둑 본인의 기록에만 남는다.
- [ ] 거절되거나 피격으로 취소된 직업 행동은 개인 기록에 추가되지 않는다.
- [ ] 사망 관전자는 전체 역할을 볼 수 있어도 다른 플레이어의 개인 행동 기록은 볼 수 없다.
- [ ] 게임 종료 후 로비 복귀 및 두 번째 경기 시작 시 이전 경기의 공개·개인 기록과 사망 일차가 남지 않는다.
- [ ] 고지연 클라이언트에서도 개인 행동 기록 RPC가 중복되거나 다른 클라이언트로 잘못 전달되지 않는다.

## 전환 화면과 투표 식별 개선

- [ ] GameScene 진입 직후 모든 클라이언트에 `게임 준비 중` 오버레이가 표시되고 뒤쪽 UI를 클릭할 수 없다.
- [ ] 역할 배정 중 오버레이에 개인별 준비 상태를 노출하지 않고 전체 `준비 완료 / 예상 인원`만 표시한다.
- [ ] 역할 배정 대기가 8초를 넘으면 `일부 플레이어의 연결을 기다리고 있습니다.`로 안내가 바뀌며, 늦은 클라이언트가 준비될 때까지 게임이 시작되지 않는다.
- [ ] 모든 클라이언트의 역할 배정이 완료되고 첫 페이즈가 시작되면 오버레이가 즉시 사라지고 조작이 정상 활성화된다.
- [ ] 게임 결과의 로비 버튼 또는 ESC 중도 이탈 확인창의 `예`를 누르면 `로비로 돌아가는 중`과 네트워크 정리 안내가 표시된다.
- [ ] 호스트와 일반 클라이언트 모두 로비 복귀가 실패하거나 지연된 상황에서 전환 중 중복 버튼 입력이 발생하지 않는다.
- [ ] 아침 투표창에서 본인 행은 진영색 `▶`로 표시되고, 생존 마녀에게 보이는 다른 마녀 행은 기존 적색 `◆`로 표시된다.
- [ ] 자유 관전자의 투표창에서 사망한 플레이어 행은 55% 밝기로 흐려지며 닉네임 첫 줄과 진영·직업 둘째 줄은 모두 읽을 수 있다.
- [ ] 투표 페이즈를 다시 열거나 다른 투표 모드로 전환하면 이전 사망 행의 투명도가 살아 있는 행에 남지 않는다.

## 화면 효과 강도와 해상도 대응

- [ ] ESC 도움말의 그래픽 탭에 프리팹으로 배치된 `화면 효과 | 보통/낮음` 설정 행이 표시된다.
- [ ] `낮음`에서는 피격 화면 효과와 제압 중 암전 맥동이 보통의 약 55% 강도로 감소하지만 완전히 사라지지 않는다.
- [ ] 설정을 변경하고 게임을 재시작해도 선택한 화면 효과 강도가 유지된다.
- [ ] 1280×720, 1920×1080, 2560×1440 및 21:9 창 모드에서 헤더, 채팅, 투표, HP·상태 HUD, TAB 현황판, 도움말과 전환 오버레이가 화면 밖으로 잘리지 않는다.
- [ ] TAB 현황판의 공개 기록과 개인 기록이 길어지면 기존 스크롤이 동작하고 고정 헤더·하단 안내와 겹치지 않는다.
- [ ] 감금, 제압, 피격 면역, 출입 제한이 겹칠 때 기존 우선순위대로 한 상태만 표시되어 HUD 높이가 흔들리지 않는다.

## 로비 복귀 실패 복구

- [ ] 게임 결과 로비 복귀와 ESC 중도 포기 모두 정상 네트워크에서는 20초 안에 기존 흐름대로 LobbyScene으로 이동하며 복구 버튼이 표시되지 않는다.
- [ ] 로비 복귀 요청을 시작하지 못하면 `로비 복귀 실패`, `다시 시도`, `닫기`가 표시되고 뒤쪽 UI는 조작되지 않는다.
- [ ] 즉시 실패 화면에서 `닫기`를 누르면 전환 오버레이가 닫히고 게임 결과 로비 버튼 또는 ESC 도움말 버튼이 다시 활성화된다.
- [ ] 즉시 실패 화면의 `다시 시도`는 최초 요청이 게임 결과 복귀인지 중도 포기인지 구분하여 동일한 경로를 다시 실행한다.
- [ ] 정상 복귀 요청 후 GameScene에 20초 이상 머물면 `로비 복귀 지연`, `다시 시도`, `나가기`가 표시된다.
- [ ] 지연 화면의 `다시 시도`를 누르면 버튼이 숨겨지고 20초 대기 시간이 새로 시작되며 NGO 씬 전환을 중복 호출하지 않는다.
- [ ] 호스트가 지연 화면의 `나가기`를 누르면 Relay 세션과 NGO 연결이 종료되고, 호스트는 LobbyScene으로 이동하며 남은 클라이언트도 예기치 않은 연결 종료 복구를 통해 LobbyScene으로 이동한다.
- [ ] 일반 클라이언트가 지연 화면의 `나가기`를 누르면 해당 클라이언트의 연결만 정리되고 호스트의 진행 중인 경기에 중복 로비 씬 요청을 보내지 않는다.
- [ ] 지연 화면의 `나가기` 이후 호스트와 클라이언트 모두 새 방 생성, 다른 방 참가 및 두 번째 게임 시작을 정상 수행할 수 있다.

## 고지연 연결 경고와 이동·타격 보정

- [ ] 호스트에는 연결 품질 경고가 표시되지 않고 일반 클라이언트에서만 서버 왕복 지연 시간을 측정한다.
- [ ] RTT가 180ms 미만인 일반 상태에서는 인게임 연결 경고 패널이 숨겨진다.
- [ ] 180~349ms 상태가 연속 측정되면 황색 `연결 지연`이 표시되고, 350ms 이상이 연속 측정되면 적색 `연결 불안정`으로 변경된다.
- [ ] 지연 수치가 임계값 부근에서 흔들려도 3개 표본 평활화, 30ms 복구 완충과 연속 표본 조건으로 경고가 빠르게 깜빡이지 않는다.
- [ ] 지연이 회복되면 연속 3회 측정 후 경고가 사라지고 연결 해제·로비 복귀·재접속 후 이전 경고 상태가 남지 않는다.
- [ ] 역할 배정 중에는 해당 로컬 클라이언트의 연결 지연·불안정만 준비 오버레이에 표시하며 지연 중인 다른 플레이어의 닉네임은 공개하지 않는다.
- [ ] 지연 경고가 표시돼도 자동 퇴장이나 핑 제한이 발생하지 않고 역할 배정 완료를 계속 기다린다.
- [ ] 180ms와 350ms 모의 지연 환경에서 소유자 본인의 이동 입력은 즉시 반응하고, 다른 클라이언트에서 보는 위치와 회전은 급격히 끊기지 않고 보간된다.
- [ ] 원격 영체가 방향을 빠르게 바꾸거나 좁은 문을 통과할 때 0.12초 보간 때문에 벽을 크게 뚫거나 장시간 뒤처지지 않는다.
- [ ] 저지연 환경의 이동과 공격 감각이 기존과 비교해 눈에 띄게 느려지지 않는다.
- [ ] 공격자는 입력 즉시 휘두르기 연출을 보고, 원격 클라이언트는 서버 시작 시각에 맞는 현재 휘두르기 구간부터 재생한다.
- [ ] 고지연 공격의 서버 위치 보정은 RTT와 이동속도를 기준으로 계산되며 최대 0.35m를 넘지 않는다.
- [ ] 클라이언트가 보고한 공격 위치가 비정상 값이거나 서버 위치에서 크게 벗어나도 서버 판정이 비정상적으로 확대되지 않는다.
- [ ] 고지연 공격도 서버에서만 피격을 확정하며 클라이언트 선판정, 중복 피해 및 공격 쿨다운 우회가 발생하지 않는다.
- [ ] 같은 집 내부 또는 양쪽 모두 집 밖이라는 기존 공격 조건이 유지되고, 문 반대편·서로 다른 집·행동 불가 상태에는 지연 보정으로 피해를 줄 수 없다.
- [ ] 일반 야간 전투, 주정뱅이 외부 제압, 저주 인형 운반자 피격 및 광장 최종 결투에서 3회 피격 규칙과 서버 결과가 기존과 동일하다.
